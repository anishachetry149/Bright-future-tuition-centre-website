Android Phone Setup

Install Bright Future on Android

  1. Save index.html to your Android phone (for example, in Downloads).
  2. Open index.html in Google Chrome.
  3. Tap the three dots (⋮) in Chrome's top-right corner and select Add to Home screen → Add / Install.
  4. Launch Bright Future from your Android Home Screen anytime. Use JSON Backup / Restore in the Admin Dashboard to back up or move saved data.
